# Student Admission Prediction using Logistic Regression

## Project Overview
This project implements a Binary Classification model using Logistic Regression to predict student admission based on two exam scores.

## Dataset
The dataset contains three columns:
- Exam 1: First exam score.
- Exam 2: Second exam score.
- Admitted: Admission status (0 or 1).

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Jupyter Notebook

## Project Workflow
1. Data Loading and Exploration
2. Data Visualization
3. Sigmoid Function Implementation
4. Cost Function Implementation
5. Data Preparation
6. Gradient Calculation
7. Model Optimization using SciPy
8. Predictions
9. Accuracy Evaluation

## Algorithm
Logistic Regression (Binary Classification).

## Project Goal
To understand and implement the mathematical foundations of Logistic Regression using Python.
